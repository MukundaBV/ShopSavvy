# 🛒 ShopSavvy – Smart E-Commerce Management System

## 📌 Project Overview

ShopSavvy is a web-based e-commerce management system developed using ASP.NET Web Forms and C#. It is designed to simplify product and inventory management by providing an organized platform for sellers and customers.

The application includes user registration, login, seller dashboard, product management and order-related functionalities.

## 🎯 Objectives

- To provide a user-friendly e-commerce management platform.
- To simplify product and inventory management.
- To provide secure user registration and login.
- To help sellers manage their products and orders efficiently.

## ✨ Features

- User Registration and Login
- Forgot Password
- Seller Login
- Seller Dashboard
- Product Management
- Order Details Management
- User-Friendly Interface

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project using Microsoft Visual Studio.

3. Open the `shopsavvy.csproj` file.

4. Configure the SQL Server database connection in `Web.config`.

5. Make sure SQL Server is installed and running.

6. Build and run the project using Visual Studio.

## 🗄️ Database Configuration

ShopSavvy uses Microsoft SQL Server for database management.

- Create or restore the project database.
- Configure the database connection string.
- Ensure the required database tables are available.

**Note:** Database credentials should never be uploaded to a public repository.
